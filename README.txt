快門實驗室｜繁體中文離線工具
版本：v2 / 2026-11-19

本版本依原對話需求重新製作；原對話的 /mnt/data 檔案未附帶到目前工作環境，未直接修改或比對原檔。

【連動規則】
公式：角度 = 360 × FPS ÷ N；快門速度 = 1/N 秒。
攝影參數推薦＋自由換算：FPS 使用 180° 原則推薦；其他欄依目前 FPS 換算。
1. 每次修改 FPS：重新推薦 180°，快門分母 N = FPS × 2。
2. 修改 N：固定目前 FPS，計算角度。
3. 修改角度：固定目前 FPS，計算 N。
改 FPS 時一律取代之前的手動角度，重新推薦 180°；FPS 快捷按鈕亦同，即使選擇相同 FPS。畫面顯示「180° 推薦」「目前幀率」「手動輸入」「自動換算」，不再使用欄位鎖定設計。
重新開啟頁面會保留上次手動設定，不會因載入而強制回到 180°。

【輸入】
三欄皆可自由輸入大於 0 的小數，使用半形小數點。快門欄只輸入分母，例如 60 即 1/60 秒。
角度範圍為大於 0 至 360°。超出範圍、空值、非數字、溢位皆不更新有效設定。
無效時保留其餘欄與圖表的最後有效結果，離開欄位還原。輸入途中每個有效值都會即時保存。
顯示最多 12 位有效數字，內部使用 JavaScript 雙精度浮點數，可能存在極微小浮點誤差。

【獨立 HTML】
以瀏覽器開啟 shutter-angle-calculator.html，即可不連網計算。
單一 HTML 的計算、樣式及介面都內嵌，不需要外部套件。
file:// 模式的設定保存依瀏覽器政策而異；保存失敗時會在「保存、安裝與離線使用」提示。
單一 HTML 並不是完整的可安裝 PWA；請用下面的完整資料夾部署。

【完整 PWA】
把本 ZIP 全部解壓到同一資料夾，再將全部檔案放至 HTTPS 靜態網站。
可部署於根目錄或子目錄，入口為 index.html。
首次連線開啟，等到右上角顯示「離線快取已就緒」。
iPhone/iPad：Safari → 分享 → 加入主畫面。
其他支援瀏覽器：使用頁面提供的「安裝工具」或瀏覽器安裝選單。
安裝提示依瀏覽器支援而異，不會在所有瀏覽器都顯示按鈕。
之後可以離線啟動及計算；清除瀏覽器網站資料或快取被系統移除後，需要重新連線。
設定存在該瀏覽器的 localStorage，不會跨裝置同步。

【檔案】
index.html：首頁，與 shutter-angle-calculator.html 內容相同。
shutter-angle-calculator.html：亦可獨立開啟的計算器。
manifest.webmanifest：PWA 名稱、啟動畫面、圖示與路徑。
sw.js：離線快取；僅清理此工具同一路徑的舊版快取。
icon-192.png / icon-512.png：安裝圖示（512 版支援 maskable）。
TEST-REPORT.txt：實際驗證範圍。
